# ChavaleteWorld

Página web de ChavaleteWorld: la app ChavaleteWords (Android) y los cursos ChavaleteSpanish y ChavaleteEnglish.

La página está en inglés y español, se cambia con el botón EN/ES de arriba.

## Archivos

- `index.html` página principal
- `privacy.html` política de privacidad de la app
- `activar.html` página para activar la app que viene con el curso
- `css/estilos.css` estilos de todas las páginas
- `js/textos.js` textos en inglés y español
- `js/main.js` cambio de idioma y la demo de la pantalla Practicar
- `js/privacidad.js` cambio de idioma en la política
- `js/activar.js` formulario de activación
- `functions/api/activar.js` entrega el código de activación de una compra
- `functions/api/hotmart.js` recibe los avisos de compra de Hotmart
- `img/logo.svg` logo

Está publicada en Cloudflare Pages. Las claves (`LLAVE_ACTIVACION`, `HOTMART_HOTTOK`) se configuran en Cloudflare y nunca van en este repositorio.
